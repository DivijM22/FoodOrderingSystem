Create user

You must be logged in as a Platform Administrator to create this account type.

Password: 8–72 characters with at least one letter and one digit. customer accounts can be created by anyone (POST /auth/register); other roles only by a signed-in platform administrator (POST /auth/users with their token). The backend enforces this either way. Delivery agents add their contact phone when they first go available.

Restaurant administrators

A restaurant can have several administrators and an administrator several restaurants; all have identical permissions. Uses POST /restaurants/:id/admins and DELETE /restaurants/:id/admins/:userId (platform admin only).

Create a restaurant
